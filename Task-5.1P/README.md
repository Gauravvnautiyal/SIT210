# Task 5.1P – Raspberry Pi LED Control

## Description

This task demonstrates controlling multiple LEDs using a Raspberry Pi.

Three LEDs were connected to GPIO pins and controlled using a Python program.

## GPIO Connections

| Component | GPIO Pin |
|-----------|----------|
| Living Room LED | GPIO 17 |
| Bathroom LED | GPIO 27 |
| Closet LED | GPIO 22 |

## Files

- `task_5_1p.py` – Python program used for the task
- `circuit.jpg` – Photo of the completed circuit
